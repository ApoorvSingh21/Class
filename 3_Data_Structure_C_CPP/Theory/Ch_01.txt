======================================================================
1.1 WHAT IS C++?
======================================================================

C++ is a general-purpose programming language.

It supports:

    • Procedural programming
    • Object-oriented programming
    • Generic programming
    • Low-level memory manipulation
    • High-performance programming

C++ is particularly useful for Data Structures and Algorithms because
it gives us direct control over memory through:

    • Pointers
    • References
    • Dynamic memory allocation

and provides the Standard Template Library (STL):

    • vector
    • stack
    • queue
    • priority_queue
    • set
    • map
    • unordered_map
    • algorithms


Example:

    #include <iostream>
    using namespace std;

    int main()
    {
        cout << "Hello World";
        return 0;
    }


======================================================================
1.2 WHY C++ FOR DATA STRUCTURES?
======================================================================

Suppose we want to create a linked list.

A linked list node contains:

    DATA + ADDRESS OF NEXT NODE

To store the address of another node, we need pointers.

Example:

    struct Node
    {
        int data;
        Node* next;
    };

Here:

    int data;
        → stores actual data

    Node* next;
        → stores address of another Node

Therefore, understanding C++ memory and pointers is extremely
important for DSA.

PART 4 — cout

    Example:

        return 0;

======================================================================
1.10 TYPE CONVERSION
======================================================================

Type conversion means converting one data type into another.


IMPLICIT CONVERSION
-------------------

The compiler performs the conversion.

Example:

    int x = 10;
    double y = x;


Conceptually:

    int
     ↓
    double


EXPLICIT CONVERSION
-------------------

You explicitly request conversion.

Example:

    double x = 10.75;

    int y = (int)x;


Modern C++ style:

    int y = static_cast<int>(x);


Example:

    int a = 5;
    int b = 2;

    double result =
        static_cast<double>(a) / b;

    cout << result;

Output:

    2.5


Without conversion:

    5 / 2

gives:

    2

because both operands are integers.

======================================================================
1.12 OPERATORS
======================================================================

Operators perform operations on values.


--------------------------------------------------
A. ARITHMETIC OPERATORS
--------------------------------------------------

    +     Addition
    -     Subtraction
    *     Multiplication
    /     Division
    %     Modulus


Example:

    int a = 10;
    int b = 3;

    cout << a + b;   // 13
    cout << a - b;   // 7
    cout << a * b;   // 30
    cout << a / b;   // 3
    cout << a % b;   // 1


IMPORTANT:

    10 / 3 = 3

when both operands are integers.


--------------------------------------------------
B. RELATIONAL OPERATORS
--------------------------------------------------

    ==    equal
    !=    not equal
    >     greater than
    <     less than
    >=    greater/equal
    <=    less/equal


Example:

    int a = 10;
    int b = 20;

    cout << (a < b);

Output:

    1

In C++:

    true  → 1
    false → 0


--------------------------------------------------
C. LOGICAL OPERATORS
--------------------------------------------------

    &&    AND
    ||    OR
    !     NOT


Example:

    int age = 25;

    if (age >= 18 && age <= 60)
    {
        cout << "Valid";
    }


AND:

    true && true   → true
    true && false  → false
    false && true  → false
    false && false → false


OR:

    true || true   → true
    true || false  → true
    false || true  → true
    false || false → false


NOT:

    !true  → false
    !false → true


--------------------------------------------------
D. ASSIGNMENT OPERATORS
--------------------------------------------------

    =
    +=
    -=
    *=
    /=
    %=


Example:

    int x = 10;

    x += 5;

Equivalent to:

    x = x + 5;


--------------------------------------------------
E. INCREMENT / DECREMENT
--------------------------------------------------

    ++
    --


Example:

    int x = 5;

    x++;

Now:

    x = 6


Prefix:

    ++x

Postfix:

    x++


Example:

    int x = 5;

    int a = ++x;

Result:

    x = 6
    a = 6


Example:

    int x = 5;

    int a = x++;

Result:

    a = 5
    x = 6


--------------------------------------------------
F. BITWISE OPERATORS
--------------------------------------------------

Important for DSA and competitive programming:

    &
    |
    ^
    ~
    <<
    >>


Example:

    int a = 5;      // 0101
    int b = 3;      // 0011

    a & b            → 0001 → 1

    a | b            → 0111 → 7

    a ^ b            → 0110 → 6


Bit shifting:

    5 << 1

Binary:

    0101 → 1010

Result:

    10


Similarly:

    10 >> 1

gives approximately:

    5


Bit manipulation becomes important later in advanced DSA.

1.13 CONDITIONAL STATEMENTS
======================================================================

Conditional statements allow a program to make decisions.


--------------------------------------------------
IF
--------------------------------------------------

    if (condition)
    {
        // code
    }


Example:

    int age = 20;

    if (age >= 18)
    {
        cout << "Adult";
    }


--------------------------------------------------
IF-ELSE
--------------------------------------------------

    if (condition)
    {
        // true
    }
    else
    {
        // false
    }


Example:

    int n = 7;

    if (n % 2 == 0)
    {
        cout << "Even";
    }
    else
    {
        cout << "Odd";
    }


--------------------------------------------------
ELSE-IF
--------------------------------------------------

    int marks = 85;

    if (marks >= 90)
    {
        cout << "A";
    }
    else if (marks >= 75)
    {
        cout << "B";
    }
    else if (marks >= 60)
    {
        cout << "C";
    }
    else
    {
        cout << "D";
    }


--------------------------------------------------
NESTED IF
--------------------------------------------------

    if (condition1)
    {
        if (condition2)
        {
            // code
        }
    }


--------------------------------------------------
SWITCH
--------------------------------------------------

Useful when selecting among fixed cases.

    int choice = 2;

    switch (choice)
    {
        case 1:
            cout << "Insert";
            break;

        case 2:
            cout << "Delete";
            break;

        case 3:
            cout << "Search";
            break;

        default:
            cout << "Invalid";
    }


IMPORTANT:

    break

prevents execution from falling into the next case.


======================================================================
1.14 LOOPS
======================================================================

Loops repeat a block of code.


Three major loops:

    1. for
    2. while
    3. do-while


--------------------------------------------------
FOR LOOP
--------------------------------------------------

Syntax:

    for (initialization; condition; update)
    {
        // code
    }


Example:

    for (int i = 0; i < 5; i++)
    {
        cout << i << " ";
    }


Output:

    0 1 2 3 4


Execution:

    i = 0
    check condition
    execute
    increment
    check again
    ...


--------------------------------------------------
WHILE LOOP
--------------------------------------------------

    int i = 0;

    while (i < 5)
    {
        cout << i << " ";
        i++;
    }


--------------------------------------------------
DO-WHILE
--------------------------------------------------

A do-while loop executes at least once.

    int i = 0;

    do
    {
        cout << i << " ";
        i++;
    }
    while (i < 5);


--------------------------------------------------
BREAK
--------------------------------------------------

Stops the loop.

    for (int i = 0; i < 10; i++)
    {
        if (i == 5)
            break;

        cout << i << " ";
    }


Output:

    0 1 2 3 4


--------------------------------------------------
CONTINUE
--------------------------------------------------

Skips the current iteration.

    for (int i = 0; i < 5; i++)
    {
        if (i == 2)
            continue;

        cout << i << " ";
    }


Output:

    0 1 3 4

1.15 FUNCTIONS
======================================================================

A function is a reusable block of code.

Why functions matter in DSA:

    • Make code modular
    • Reduce repetition
    • Make algorithms easier to understand
    • Allow recursive algorithms
    • Allow separate operations such as insert(), delete(), search()


Basic syntax:

    return_type function_name(parameters)
    {
        // body
        return value;
    }


Example:

    int add(int a, int b)
    {
        return a + b;
    }


Call:

    int result = add(10, 20);


result:

    30


--------------------------------------------------
FUNCTION WITH NO RETURN VALUE
--------------------------------------------------

    void printHello()
    {
        cout << "Hello";
    }


--------------------------------------------------
FUNCTION WITH NO PARAMETERS
--------------------------------------------------

    int getNumber()
    {
        return 10;
    }


--------------------------------------------------
PASS BY VALUE
--------------------------------------------------

A copy is passed.

    void change(int x)
    {
        x = 100;
    }

    int a = 10;

    change(a);

    cout << a;


Output:

    10


The original value is unchanged.


--------------------------------------------------
PASS BY REFERENCE
--------------------------------------------------

The function receives a reference to the original variable.

    void change(int& x)
    {
        x = 100;
    }

    int a = 10;

    change(a);

Now:

    a = 100


This is extremely useful in DSA.


--------------------------------------------------
FUNCTION OVERLOADING
--------------------------------------------------

Multiple functions can have the same name if their parameter lists
differ.

    int add(int a, int b)
    {
        return a + b;
    }

    double add(double a, double b)
    {
        return a + b;
    }

1.16 SCOPE

Scope tells us where a variable can be accessed.


LOCAL VARIABLE:

    void test()
    {

1.17 ARRAYS
======================================================================

An array stores multiple values of the same type in contiguous memory.


Example:

    int arr[5];


Initialization:

    int arr[5] = {10, 20, 30, 40, 50};


Indexing starts from:

    0


Therefore:

    arr[0] = 10
    arr[1] = 20
    arr[2] = 30
    arr[3] = 40
    arr[4] = 50


Access:

    cout << arr[2];

Output:

    30


Traversal:

    for (int i = 0; i < 5; i++)
    {
        cout << arr[i] << " ";
    }


Memory concept:

    arr[0] arr[1] arr[2] arr[3] arr[4]
       ↓      ↓      ↓      ↓      ↓
      10     20     30     40     50

The elements are stored contiguously.


This is important because:

    arr[i]

can be accessed in O(1) time.

1.19 POINTERS
======================================================================

THIS IS ONE OF THE MOST IMPORTANT TOPICS FOR DSA.


A pointer is a variable that stores the memory address of another
variable.


Example:

    int x = 10;

    int* p = &x;


Here:

    x
        → integer variable

    &x
        → address of x

    p
        → stores address of x

    *p
        → value stored at that address


Concept:

            x
        +---------+
        |   10    |
        +---------+
             ↑
             |
             |
             p
        +---------+
        | address |
        +---------+


Address operator:

    &


Dereference operator:

    *


Example:

    int x = 10;

    int* p = &x;

    cout << x;      // 10
    cout << &x;     // address
    cout << p;      // same address
    cout << *p;     // 10


IMPORTANT:

    p  → address

    *p → value at address


======================================================================
1.20 POINTER BASICS
======================================================================

Declaration:

    int* p;


Initialization:

    int x = 10;

    int* p = &x;


Modify x through pointer:

    *p = 50;


Now:

    x = 50


Example:

    int x = 10;

    int* p = &x;

    *p = 100;

    cout << x;


Output:

    100


Why?

Because p points to x.

1.21 NULL POINTER AND nullptr
======================================================================

A pointer should not contain an invalid/random address.

    nullptr


Example:

    int* p = nullptr;


Check:

    if (p == nullptr)
    {

    }


Modern C++ recommendation:

    Use nullptr

instead of the older:

    NULL


======================================================================
1.22 POINTER ARITHMETIC
======================================================================

Suppose:

    int arr[5] = {10, 20, 30, 40, 50};

    int* p = arr;


Then:

    *p       → 10

    *(p + 1) → 20

    *(p + 2) → 30

    *(p + 3) → 40

    *(p + 4) → 50


Conceptually:

    p
    ↓
    [10][20][30][40][50]
     0   1   2   3   4


p + 1 points to the next int element.

The actual address increment depends on the size of the pointed-to
type.


IMPORTANT:

    p + 1

does NOT necessarily mean "one byte later".

It means:

    move by sizeof(*p) bytes.


======================================================================
1.23 POINTERS AND ARRAYS
======================================================================

An array name can often be used as a pointer to its first element.

Example:

    int arr[3] = {10, 20, 30};


Then:

    arr

conceptually refers to:

    &arr[0]


Therefore:

    *arr

means:

    arr[0]


And:

    *(arr + 1)

means:

    arr[1]


Example:

    cout << arr[0];
    cout << *(arr + 0);

Both produce:

    10


Similarly:

    cout << arr[2];
    cout << *(arr + 2);

Both produce:

    30


This relationship becomes very important in linked lists,
trees, graphs and dynamic data structures.

Pointers can be passed to functions.

1.25 REFERENCES
======================================================================

A reference is another name (alias) for an existing variable.


Example:

    int x = 10;

    int& ref = x;


Now:

    x
    ref

refer to the same object.


Example:

    ref = 50;

    cout << x;


Output:

    50


Because ref and x refer to the same object.


--------------------------------------------------
REFERENCE WITH FUNCTION
--------------------------------------------------

    void change(int& x)
    {
        x = 100;
    }

    int a = 10;

    change(a);

Now:

    a = 100


This is called:

    Pass by reference


======================================================================
1.26 POINTERS VS REFERENCES
======================================================================

POINTER:

    int* p;

    Can be nullptr.

    Can be changed to point somewhere else.

    Access value using:

        *p


REFERENCE:

    int& r = x;

    Must refer to an existing object when initialized.

    Cannot normally be reseated to refer to another object.

    Access value directly:

        r


Quick comparison:

    +----------------------+----------------------+
    | Pointer              | Reference            |
    +----------------------+----------------------+
    | Stores address       | Alias of object      |
    | Can be nullptr       | Normally cannot      |
    | Can be reseated       | Cannot be reseated   |
    | Uses * to dereference| Direct access        |
    +----------------------+----------------------+


DSA uses both extensively.


======================================================================
1.27 DYNAMIC MEMORY ALLOCATION
======================================================================

Normally:

    int x = 10;

creates an object with automatic storage duration.

Dynamic memory allows us to request storage during program execution.

C++ uses:

    new
    delete


Example:

    int* p = new int;

Now memory for one int is dynamically allocated.


Assign:

    *p = 50;


Use:

    cout << *p;


Release:

    delete p;

Then:

    p = nullptr;


Complete example:

    int* p = new int;

    *p = 50;

    cout << *p;

    delete p;
    p = nullptr;


IMPORTANT:

Every dynamically allocated object should eventually be released
when you are responsible for it.

Otherwise, a memory leak can occur.


======================================================================
1.28 DYNAMIC ARRAY
======================================================================

Example:

    int n;

    cin >> n;

    int* arr = new int[n];


Now arr points to dynamically allocated storage for n integers.


Use:

    arr[0] = 10;
    arr[1] = 20;


Release:

    delete[] arr;

    arr = nullptr;


IMPORTANT:

For:

    new int

use:

    delete


For:

    new int[n]

use:

    delete[]


Mismatch is incorrect:

    new int[n]
    delete p;

Correct:

    new int[n]
    delete[] p;


In modern C++, prefer standard containers such as:

    vector<int>

when you do not specifically need manual memory management.

1.29 STRUCTURES
======================================================================

A structure allows us to group related data.


Example:

    struct Student
    {
        string name;
        int age;
        double marks;
    };


Create object:

    Student s;


Assign:

    s.name = "Apoorv";
    s.age = 22;
    s.marks = 85.5;


Access:

    cout << s.name;


Structures are extremely important in Data Structures.


Example linked-list node:

    struct Node
    {
        int data;
        Node* next;
    };


Create:

    Node* first = new Node;


Assign:

    first->data = 10;
    first->next = nullptr;


Here:

    first

is a pointer to Node.

The:

    ->

operator is used to access a member through a pointer.


Equivalent concept:

    (*first).data

is equivalent to:

    first->data

======================================================================
1.31 ACCESS SPECIFIERS
======================================================================

C++ commonly provides:

    public
    private
    protected


PUBLIC:

Members can be accessed from outside the class.

Example:

    class Student
    {
    public:
        int age;
    };


PRIVATE:

Members cannot be accessed directly from outside.

Example:

    class Student
    {
    private:
        int age;
    };


This helps with:

    Encapsulation


======================================================================
1.32 CONSTRUCTORS
======================================================================

A constructor initializes an object.

It has the same name as the class and no return type.


Example:

    class Student
    {
    public:

        string name;
        int age;

        Student()
        {
            name = "Unknown";
            age = 0;
        }
    };


Create:

    Student s;


The constructor automatically executes.


PARAMETERIZED CONSTRUCTOR:

    class Student
    {
    public:

        string name;
        int age;

        Student(string n, int a)
        {
            name = n;
            age = a;
        }
    };


Create:

    Student s("Apoorv", 22);


In modern C++, member initializer lists are often preferred:

    Student(string n, int a)
        : name(n), age(a)
    {
    }


This becomes useful when creating complex data structures.

ENCAPSULATION
--------------------------------------------------

Combining data and functions inside a class.

Example:

    class Stack
    {

--------------------------------------------------

1.37 PAIR
======================================================================

pair stores two values together.

    p.first
    p.second

    • Graphs
    • Priority queues
    • Sorting
    • Maps
    • Coordinate problems

Represents:

    (10, 20)

1.38 PASSING STL CONTAINERS TO FUNCTIONS
======================================================================

Avoid unnecessary copying.

Instead of:

    void print(vector<int> arr)

prefer, when the function does not modify the vector:

    void print(const vector<int>& arr)


Example:

    void print(const vector<int>& arr)
    {
        for (int x : arr)
        {
            cout << x << " ";
        }
    }


Why?

    const
        → function promises not to modify arr

    &
        → avoids copying the entire vector


This becomes important for performance.

1.42 COMPLETE EXAMPLE — POINTER + ARRAY
======================================================================

    #include <iostream>
    using namespace std;

    int main()
    {
        int arr[5] = {10, 20, 30, 40, 50};

        int* p = arr;

        for (int i = 0; i < 5; i++)
        {
            cout << *(p + i) << " ";
        }

        return 0;
    }


Output:

    10 20 30 40 50


Important relationship:

    arr[i]

is equivalent to:

    *(arr + i)


and, when p points to the first element:

    *(p + i)


This concept is fundamental for understanding memory-based
data structures.


======================================================================
1.43 COMPLETE EXAMPLE — LINKED LIST NODE
======================================================================

This is your first bridge from C++ to Data Structures.

    #include <iostream>
    using namespace std;

    struct Node
    {
        int data;
        Node* next;
    };

    int main()
    {
        Node* first = new Node;

        first->data = 10;
        first->next = nullptr;

        cout << first->data;

        delete first;
        first = nullptr;

        return 0;
    }


Output:

    10


What happened?

Step 1:

    struct Node

created a user-defined type.


Step 2:

    Node* first

created a pointer capable of storing the address of a Node.


Step 3:

    new Node

dynamically created a Node.


Step 4:

    first->data = 10

stored 10 inside the node.


Step 5:

    first->next = nullptr

indicated that there is currently no next node.


This is the foundation of:

    Linked Lists
    Trees
    Graphs

1.46 COMMON BEGINNER MISTAKES
======================================================================

MISTAKE 1 — Using = instead of ==

Wrong:

    if (x = 10)

Correct:

    if (x == 10)


MISTAKE 2 — Array index out of bounds

Wrong:

    int arr[5];

    cout << arr[5];

Valid indices:

    0 to 4


MISTAKE 3 — Uninitialized pointer

Dangerous:

    int* p;

    *p = 10;


Correct:

    int x = 10;

    int* p = &x;


or:

    int* p = nullptr;


MISTAKE 4 — Forgetting delete

If you manually allocate:

    int* p = new int(10);

then release it:

    delete p;


MISTAKE 5 — Wrong delete

For:

    new int[n]

use:

    delete[]


MISTAKE 6 — Integer division

    5 / 2

produces:

    2


Use:

    5.0 / 2

or appropriate casting for:

    2.5


MISTAKE 7 — Infinite loop

    int i = 0;

    while (i < 10)
    {
        cout << i;
    }


i never changes.

Correct:

    i++;


MISTAKE 8 — Forgetting break in switch

Can cause fall-through into subsequent cases.


MISTAKE 9 — Returning reference/pointer to an object whose lifetime
has ended.

This is a more advanced lifetime issue, but you should learn to
recognize that an address is only useful while the referenced object
still exists.

1.48 MINI DSA EXAMPLE — LINEAR SEARCH
======================================================================

    #include <iostream>
    using namespace std;

    int linearSearch(int arr[], int n, int target)
    {
        for (int i = 0; i < n; i++)
        {
            if (arr[i] == target)
            {
                return i;
            }
        }

        return -1;
    }

    int main()
    {
        int arr[] = {10, 20, 30, 40, 50};

        int n = 5;

        int target = 30;

        int index = linearSearch(arr, n, target);

        cout << index;

        return 0;
    }


Output:

    2


Complexity:

    Best case:
        O(1)

    Worst case:
        O(n)

    Space:
        O(1)


This is the first example of applying C++ programming to DSA.
