===============================================================
1.1 WHAT IS PROGRAMMING?
===============================================================

Programming means giving a computer a set of instructions
that tells it:

    - What to do
    - How to do it
    - When to do it
    - What result to produce

A computer does not automatically know how to solve a problem.
We provide instructions using a programming language.

Example:

Problem:
    Add two numbers.

Human thinking:
    1. Take first number.
    2. Take second number.
    3. Add them.
    4. Display the result.

Python program:

    a = 10
    b = 20
    result = a + b
    print(result)

Output:

    30


Real-world analogy:

    You want to order food.

    You tell the delivery person:

        1. Go to restaurant.
        2. Order food.
        3. Pay for food.
        4. Bring food to me.

    These are instructions.

Similarly, a computer needs instructions.

    Human Problem
          ↓
    Algorithm / Steps
          ↓
    Program
          ↓
    Computer Executes Program
          ↓
    Output


IMPORTANT:

Programming is NOT just writing code.

Programming involves:

    Problem
       ↓
    Understanding
       ↓
    Algorithm
       ↓
    Coding
       ↓
    Testing
       ↓
    Debugging
       ↓
    Final Solution


===============================================================
1.2 WHAT IS A PROGRAM?
===============================================================

A program is a collection of instructions written to solve
a particular problem or perform a particular task.

Example:

    print("Hello World")

This is a very small Python program.

It tells Python:

    "Display Hello World on the screen."

Output:

    Hello World


Another example:

    name = "Apoorv"
    print(name)

Output:

    Apoorv


A large application is also a collection of programs/modules.

Examples:

    WhatsApp
    Google Chrome
    Banking Applications
    Operating Systems
    E-commerce Websites
    AI Applications

All are built using many software components and programs.


===============================================================
1.3 WHAT IS A PROGRAMMING LANGUAGE?
===============================================================

A programming language is a formal language used by humans
to write instructions that computers can execute.

Examples:

    C
    C++
    Java
    Python
    JavaScript
    Go
    Rust
    C#

Different languages have different syntax, features and
typical use cases.

Example:

C:

    printf("Hello World");

C++:

    cout << "Hello World";

Java:

    System.out.println("Hello World");

Python:

    print("Hello World")


The task is the same:

    Display "Hello World"

But the way we express the instruction is different.


===============================================================
1.4 WHY DO WE NEED PROGRAMMING LANGUAGES?
===============================================================

Computers fundamentally work with electrical signals and
machine-level instructions.

Humans prefer readable instructions such as:

    calculate salary
    search student
    sort numbers
    open file

Computers ultimately need machine-level instructions.

Programming languages provide a bridge:

    Human Thinking
          ↓
    Programming Language
          ↓
    Translator / Runtime System
          ↓
    Machine-Level Execution
          ↓
    Computer


===============================================================
1.5 LOW-LEVEL VS HIGH-LEVEL LANGUAGES
===============================================================

Programming languages can broadly be discussed as:

    1. Low-level languages
    2. High-level languages


-------------------------
1.5.1 LOW-LEVEL LANGUAGE
-------------------------

A low-level language is closer to the hardware.

Examples:

    Machine Language
    Assembly Language

Advantages:

    - High hardware control
    - Potentially very efficient
    - Useful for system-level programming

Disadvantages:

    - Difficult for humans
    - Hardware dependent in many cases
    - More difficult to develop and maintain


-------------------------
1.5.2 HIGH-LEVEL LANGUAGE
-------------------------

A high-level language is designed to be easier for humans
to read and write.

Examples:

    Python
    Java
    C++
    JavaScript
    C#

Example:

    x = 10
    y = 20
    print(x + y)

This is much easier for a human to understand than raw
machine instructions.


IMPORTANT:

"High-level" does NOT mean "better in every situation."

The appropriate language depends on the problem.


===============================================================
1.6 WHAT IS MACHINE LANGUAGE?
===============================================================

Machine language consists of instructions represented in a
form directly understood by the processor.

It is commonly represented using binary values:

    0 and 1

Conceptually:

    10110000
    11001010
    00010101

The exact machine instructions depend on the processor's
instruction set architecture (ISA).

Examples of processor architectures include:

    x86-64
    ARM
    RISC-V


Problem with machine language:

    It is extremely difficult for humans to write and
    understand directly.


===============================================================
1.7 WHAT IS ASSEMBLY LANGUAGE?
===============================================================

Assembly language uses symbolic instructions instead of
writing raw binary instructions.

Example:

    MOV AX, 10
    ADD AX, 20

Here:

    MOV = move data
    ADD = add data

An assembler translates assembly language into machine code.

Conceptually:

    Assembly Code
          ↓
       Assembler
          ↓
    Machine Code


===============================================================
1.8 WHAT IS SOURCE CODE?
===============================================================

Source code is the human-readable program written by a
programmer using a programming language.

Example Python source code:

    name = "Apoorv"
    age = 22

    print(name)
    print(age)

This is source code.

It is stored in a Python file, normally with:

    .py

Example:

    program.py


===============================================================
1.9 WHAT IS OBJECT CODE?
===============================================================

Object code is a machine-oriented representation produced
during compilation.

In traditional compiled languages such as C/C++, source code
is commonly transformed into object files before linking.

Conceptually:

    Source Code
          ↓
       Compiler
          ↓
      Object Code
          ↓
       Linker
          ↓
      Executable


Python's normal execution model is different and uses
bytecode and a Python runtime.


===============================================================
1.10 WHAT IS BYTECODE?
===============================================================

Bytecode is an intermediate representation of a program.

In CPython, Python source code is compiled into Python
bytecode, which is then executed by the Python virtual machine
inside the CPython interpreter.

Conceptually:

    Python Source Code
           ↓
      Python Compiler
           ↓
      Python Bytecode
           ↓
       Python Runtime
           ↓
        Execution


You may see cached bytecode in files such as:

    __pycache__/

with files that commonly have a:

    .pyc

extension.

IMPORTANT:

Python bytecode is NOT the same thing as CPU machine code.

It is intended for execution by the Python runtime.


===============================================================
1.11 COMPILER
===============================================================

A compiler is a program that translates source code from one
form/language into another form, often before execution.

For a traditional compiled language:

    Source Code
         ↓
      Compiler
         ↓
    Machine/Object Code
         ↓
      Execution


Examples of commonly compiled languages:

    C
    C++
    Rust
    Go


Example C:

    #include <stdio.h>

    int main() {
        printf("Hello");
        return 0;
    }

A C compiler translates the source program into
machine-oriented code that can be executed by the target
system.


===============================================================
1.12 INTERPRETER
===============================================================

An interpreter is a program/runtime system that executes
program instructions.

The exact implementation model varies by language.

A common simplified teaching model is:

    Source Code
         ↓
      Interpreter
         ↓
      Execution


For Python, it is more accurate to say:

    Python Source
         ↓
    Compile to Bytecode
         ↓
    Python Runtime
         ↓
    Execute Bytecode


IMPORTANT:

Do not memorize:

    "Python is only interpreted."

That is an oversimplification.

CPython first compiles Python source into bytecode and then
executes that bytecode using its runtime.


===============================================================
1.13 COMPILER VS INTERPRETER
===============================================================

Compiler-oriented model:

    Source Code
         ↓
      Compiler
         ↓
    Target Code
         ↓
      Execution

Interpreter-oriented model:

    Source Code
         ↓
    Interpreter
         ↓
      Execution


Traditional comparison:

    Compiler:
        - Translation is generally performed before execution.
        - Produces target/object/executable code.
        - Errors are often reported during compilation.

    Interpreter:
        - Executes program instructions through a runtime.
        - Usually does not produce a standalone native executable
          in the same way as a traditional ahead-of-time compiler.


Python:

    Source Code
         ↓
    CPython Compiler
         ↓
      Bytecode
         ↓
    Python Virtual Machine
         ↓
      Execution


===============================================================
1.14 WHY IS PYTHON CALLED A HIGH-LEVEL LANGUAGE?
===============================================================

Python provides abstractions that allow programmers to focus
on solving problems rather than managing hardware details.

Example:

    numbers = [10, 20, 30, 40]

    print(sum(numbers))

A programmer does not need to manually:

    - allocate raw memory for every integer
    - calculate memory addresses
    - manually release memory
    - write CPU instructions

Python provides these abstractions.

===============================================================
1.19 LIMITATIONS OF PYTHON
===============================================================

Python is powerful, but it is not perfect.

1. PERFORMANCE

For some CPU-intensive workloads, Python can be slower than
languages such as C/C++.

2. MEMORY USAGE

Python objects can have relatively high memory overhead.

3. GIL IN CPYTHON

The Global Interpreter Lock (GIL) has historically limited
execution of multiple Python threads for CPU-bound Python code
in standard CPython configurations.

Python's threading is still very useful for many I/O-bound
workloads.

Modern Python versions also provide evolving options around
free-threaded execution, so the exact behavior depends on the
Python build/version being used.

4. MOBILE/LOW-LEVEL SYSTEMS

Python is generally not the first choice for many
resource-constrained or low-level systems.

5. RUNTIME DEPENDENCY

Typical Python programs require an appropriate Python runtime
and dependencies to be installed.

===============================================================
1.23 WHAT HAPPENS WHEN YOU RUN A PYTHON PROGRAM?
===============================================================

Suppose we create:

    hello.py

Containing:

    print("Hello World")


When executed using CPython, conceptually:

    Step 1:
        Operating system starts Python.

    Step 2:
        Python reads the source code.

    Step 3:
        Python parses and compiles the source into
        Python bytecode.

    Step 4:
        The Python runtime executes the bytecode.

    Step 5:
        print() writes the text to standard output.

Result:

    Hello World


Simplified architecture:

    hello.py
       ↓
    Python Parser / Compiler
       ↓
    Bytecode
       ↓
    CPython Runtime
       ↓
    Operating System
       ↓
    Hardware
       ↓
    Output

1.27 WHAT IS SYNTAX?
===============================================================

Syntax means the rules for writing valid programs in a
programming language.

Correct Python:

    if age >= 18:
        print("Adult")


Incorrect Python:

    if age >= 18
        print("Adult")


The second example is invalid because the syntax is incorrect.


Think of syntax like grammar.

English:

    "I am going to college."

Correct sentence structure.

Programming:

    if age >= 18:
        print("Adult")

Correct Python syntax.


===============================================================
1.28 WHAT IS SEMANTICS?
===============================================================

Semantics means the meaning/behavior of a valid program.

Example:

    x = 10
    y = 20
    print(x + y)

Syntax:
    Correct.

Meaning:
    Add x and y and display the result.


Difference:

    Syntax  = Is the program written correctly?
    Semantics = What does the program mean/do?


===============================================================
1.29 SYNTAX ERROR
===============================================================

A syntax error occurs when Python cannot parse the program
according to Python's grammar.

Example:

    if True
        print("Hello")

The colon is missing.

Python reports a SyntaxError.


===============================================================
1.30 RUNTIME ERROR
===============================================================

A runtime error occurs while the program is executing.

Example:

    a = 10
    b = 0

    print(a / b)

This causes:

    ZeroDivisionError


The program syntax is valid, but the operation cannot be
performed as written.


===============================================================
1.31 LOGICAL ERROR
===============================================================

A logical error occurs when the program runs but produces an
incorrect result because the algorithm or logic is wrong.

Example:

    length = 10
    width = 5

    area = length + width

Correct formula:

    area = length * width


The program may execute successfully but give the wrong answer.

This is why testing and problem-solving are important.


===============================================================

Common categories:

    Syntax errors

    Logical errors

    x = 10

Debugging process:

    Identify problem
         ↓

===============================================================
1.33 ALGORITHM
===============================================================

An algorithm is a finite sequence of well-defined steps used
to solve a problem.

Problem:

    Find the larger of two numbers.

Algorithm:

    Step 1: Start
    Step 2: Read A
    Step 3: Read B
    Step 4: Compare A and B
    Step 5: If A > B, A is larger
    Step 6: Otherwise B is larger
    Step 7: Stop


Python implementation:

    a = 10
    b = 20

    if a > b:
        print(a)
    else:
        print(b)


Important:

    Algorithm = solution procedure
    Program = implementation of that procedure

Conceptually:

    Computer
       |
       +---- Project A
       |       |
       |      venv
       |
       +---- Project B
               |
              venv


Typical command:

    python -m venv .venv


Activation commands depend on the operating system/shell.

===============================================================
1.48 COMMENTS
===============================================================

Comments are notes written for humans and are ignored as
normal executable Python statements.

Single-line comment:

    # This is a comment

Example:

    age = 22

    # Display age
    print(age)


Comments should explain useful context, not obvious syntax.

Good:

    # Convert Celsius to Fahrenheit
    fahrenheit = (celsius * 9/5) + 32


Avoid unnecessary comments such as:

    # Add 1 to x
    x = x + 1

    - Code layout

Programming
    → Writing instructions to solve problems.

1.56 CHAPTER 1 INTERVIEW QUESTIONS
===============================================================

Q1. What is programming?

Answer:
    Programming is the process of creating instructions that
    a computer can execute to solve a problem or perform a task.


Q2. What is Python?

Answer:
    Python is a high-level, general-purpose programming
    language known for readable syntax and a large ecosystem.


Q3. Who created Python?

Answer:
    Guido van Rossum.


Q4. When was Python first publicly released?

Answer:
    1991.


Q5. Is Python compiled or interpreted?

Answer:
    The common "compiled vs interpreted" distinction is
    oversimplified for Python. In CPython, source code is
    compiled to bytecode and that bytecode is executed by
    the Python runtime.


Q6. What is bytecode?

Answer:
    Bytecode is an intermediate representation produced from
    Python source code and executed by the Python runtime.


Q7. What is CPython?

Answer:
    CPython is the reference implementation of Python and
    is primarily implemented in C.


Q8. What is a high-level language?

Answer:
    A language that provides abstractions closer to human
    problem-solving and hides many hardware-level details.


Q9. What is source code?

Answer:
    Human-readable code written by a programmer.


Q10. What is an algorithm?

Answer:
    A finite sequence of well-defined steps for solving a
    problem.


Q11. What is debugging?

Answer:
    The process of identifying and fixing errors in software.


Q12. What is dynamic typing?

Answer:
    A variable name does not need a fixed declared type;
    it can refer to objects of different types at different
    times.


Q13. Is Python strongly typed?

Answer:
    Yes. Python generally enforces type rules rather than
    automatically performing arbitrary implicit conversions
    between unrelated types.


Q14. What is pip?

Answer:
    A package installation tool commonly used for Python.


Q15. What is PyPI?

Answer:
    Python Package Index, a major repository for Python
    packages.
