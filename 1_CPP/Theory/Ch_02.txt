2.1 WHAT IS C++?
====================================================================

C++ is a general-purpose programming language designed for
high performance, systems programming, and large-scale software
development.

C++ supports multiple programming styles, including:

    - Procedural Programming
    - Object-Oriented Programming
    - Generic Programming
    - Functional-style programming
    - Low-level/system-oriented programming


Simple definition:

    C++ is a powerful general-purpose programming language that
    combines high-level abstractions with low-level control.


Example:

    #include <iostream>

    int main()
    {
        std::cout << "Hello World";
        return 0;
    }


Output:

    Hello World


====================================================================
2.2 WHY IS C++ IMPORTANT?
====================================================================

C++ is important because it provides:

    1. High performance
    2. Memory control
    3. Object-oriented programming
    4. Generic programming
    5. Rich Standard Library
    6. Strong type checking
    7. Low-level hardware access
    8. High-level abstractions
    9. Large ecosystem
    10. Portability across many platforms


C++ allows programmers to write code such as:

    std::vector<int> numbers;

while also allowing lower-level operations such as:

    int* ptr = &value;


Therefore C++ can be used at different abstraction levels.

2.4 WHO CREATED C++?
====================================================================

C++ was created by:

    Bjarne Stroustrup

He worked at:

    Bell Labs

C++ originally evolved from work on:

    "C with Classes"


The original goal was to combine the efficiency and systems
programming capabilities of C with features such as classes and
abstraction.


====================================================================
2.5 WHY WAS C++ CREATED?
====================================================================

C is powerful and efficient, but large software systems can
benefit from stronger abstraction and organization mechanisms.

Bjarne Stroustrup wanted a language that could provide:

    - C-like performance
    - Systems programming capabilities
    - Object-oriented features
    - Better organization of large programs
    - Abstraction
    - Reusability


This led to the development of C++.


====================================================================
2.6 MEANING OF "C++"
====================================================================

The name:

    C++

comes from the C language.

The operator:

    ++

is the increment operator in C/C++.

Conceptually:

    C
    +
    ++
    =
    C++


The name suggests an evolution of C.

IMPORTANT:
----------
Do not interpret the name as meaning that C++ is simply
"C plus a few features."

Modern C++ has evolved into a large language with many
features and abstractions.


====================================================================
2.7 C++ IS NOT JUST AN OOP LANGUAGE
====================================================================

A common beginner misconception is:

    "C++ = Object-Oriented Programming"


This is incomplete.

C++ supports several programming paradigms.

--------------------------------------------------
1. Procedural Programming
--------------------------------------------------

Example:

    int add(int a, int b)
    {
        return a + b;
    }


--------------------------------------------------
2. Object-Oriented Programming
--------------------------------------------------

Example:

    class Student
    {
    public:
        void display()
        {
            std::cout << "Student";
        }
    };


--------------------------------------------------
3. Generic Programming
--------------------------------------------------

Example:

    template <typename T>
    T maximum(T a, T b)
    {
        return a > b ? a : b;
    }


--------------------------------------------------
4. Functional-style Programming
--------------------------------------------------

Example:

    auto square = [](int x)
    {
        return x * x;
    };


Therefore:

    C++ = Multi-Paradigm Language

====================================================================
2.9 FEATURE — OBJECT-ORIENTED PROGRAMMING
====================================================================

C++ supports OOP concepts such as:

    Class
    Object
    Encapsulation
    Abstraction
    Inheritance
    Polymorphism


Example:

    class Car
    {
    public:
        void start()
        {
            std::cout << "Car Started";
        }
    };


Create object:

    Car car;

Call function:

    car.start();


OOP is extremely important for C++ interviews.


====================================================================
2.10 FEATURE — ENCAPSULATION
====================================================================

Encapsulation means combining data and the operations that work
on that data while controlling access to the internal state.

Example:

    class BankAccount
    {
    private:
        double balance;

    public:
        void deposit(double amount)
        {
            balance += amount;
        }
    };


Here:

    balance

is private.

External code cannot directly access it in the normal way.

This helps protect object state.


====================================================================
2.11 FEATURE — ABSTRACTION
====================================================================

Abstraction means exposing the important interface while hiding
unnecessary implementation details.

Example:

    car.start();


The user does not need to know every internal step required to
start the engine.

In software:

    Interface
       |
       v
    Implementation hidden


Abstraction helps manage complexity.


====================================================================
2.12 FEATURE — INHERITANCE
====================================================================

Inheritance allows a class to derive from another class.

Example:

    class Animal
    {
    public:
        void eat()
        {
            std::cout << "Eating";
        }
    };


    class Dog : public Animal
    {
    };


Now Dog can use inherited functionality:

    Dog d;
    d.eat();


Inheritance supports code reuse and hierarchical relationships.


====================================================================
2.13 FEATURE — POLYMORPHISM
====================================================================

Polymorphism means "many forms."

C++ supports:

    Compile-time polymorphism
        - Function overloading
        - Operator overloading

    Runtime polymorphism
        - Virtual functions
        - Overriding


Example:

    void print(int x);

    void print(double x);


Same function name, different parameter types.


Detailed polymorphism will be covered later.


====================================================================
2.14 FEATURE — FUNCTION OVERLOADING
====================================================================

Multiple functions can have the same name if their parameter
lists differ.

Example:

    int add(int a, int b)
    {
        return a + b;
    }

    double add(double a, double b)
    {
        return a + b;
    }


Usage:

    add(10, 20);

    add(10.5, 20.5);


The compiler selects the appropriate function based on arguments.


====================================================================
2.15 FEATURE — OPERATOR OVERLOADING
====================================================================

C++ allows many operators to be given custom behavior for
user-defined types.

For example:

    +

can be overloaded for a class.

Conceptually:

    object1 + object2


This can make user-defined types behave naturally.

Example:

    Complex a;
    Complex b;

    Complex c = a + b;


The meaning of + can be defined by the programmer for Complex.


====================================================================
2.16 FEATURE — TEMPLATES
====================================================================

Templates support generic programming.

Instead of writing separate functions:

    int max()
    double max()
    float max()

we can create a generic function:

    template <typename T>
    T maximum(T a, T b)
    {
        return a > b ? a : b;
    }


Then:

    maximum(10, 20);

    maximum(10.5, 20.5);


Templates are the foundation of much of the STL.


====================================================================
2.17 FEATURE — STL
====================================================================

STL means:

    Standard Template Library

It provides reusable components such as:

    vector
    list
    deque
    stack
    queue
    set
    map
    unordered_map
    algorithms
    iterators


Example:

    #include <vector>

    std::vector<int> numbers = {10, 20, 30};


Instead of implementing a dynamic array from scratch,
you can use vector.


STL is extremely important for:

    - DSA
    - Coding interviews
    - Competitive programming
    - Professional C++ development


====================================================================
2.18 FEATURE — EXCEPTION HANDLING
====================================================================

C++ provides exception handling using:

    try
    catch
    throw


Example:

    try
    {
        throw std::runtime_error("Something went wrong");
    }
    catch (const std::exception& e)
    {
        std::cout << e.what();
    }


Exceptions allow programs to handle certain exceptional
conditions in a structured manner.


====================================================================
2.19 FEATURE — POINTERS
====================================================================

C++ provides pointers.

Example:

    int x = 10;

    int* ptr = &x;


Here:

    x
      = integer variable

    &x
      = address of x

    ptr
      = pointer storing the address


Pointers are important for:

    - Dynamic memory
    - Data structures
    - Systems programming
    - Performance-sensitive programming
    - Low-level operations


====================================================================
2.20 FEATURE — REFERENCES
====================================================================

C++ supports references.

Example:

    int x = 10;

    int& ref = x;


Here:

    ref

is another name (alias) for x.


References are widely used for:

    - Function parameters
    - Avoiding unnecessary copies
    - Const references
    - Operator overloading
    - Generic programming


====================================================================
2.21 FEATURE — SMART POINTERS
====================================================================

Modern C++ provides smart pointers.

Important types:

    std::unique_ptr
    std::shared_ptr
    std::weak_ptr


Example:

    std::unique_ptr<int> ptr =
        std::make_unique<int>(10);


Smart pointers help manage dynamically allocated resources
automatically according to ownership semantics.

They are closely related to:

    RAII
    Resource ownership
    Object lifetime


====================================================================
2.22 FEATURE — RAII
====================================================================

RAII means:

    Resource Acquisition Is Initialization


It is one of the most important C++ resource-management concepts.

The basic idea is:

    Resource lifetime
          =
    Object lifetime


Resources can include:

    - Memory
    - Files
    - Locks
    - Sockets
    - Other system resources


Example:

    {
        std::lock_guard<std::mutex> lock(m);
        // critical section
    }

When lock goes out of scope, it is automatically released.


RAII is a major reason modern C++ can manage resources safely
without requiring explicit cleanup at every location.


====================================================================
2.23 FEATURE — LAMBDA EXPRESSIONS
====================================================================

A lambda is an unnamed function object that can be written
directly where needed.

Example:

    auto square = [](int x)
    {
        return x * x;
    };


Usage:

    std::cout << square(5);


Output:

    25


Lambdas are heavily used with STL algorithms.

Example:

    std::sort(v.begin(), v.end(),
        [](int a, int b)
        {
            return a > b;
        });


====================================================================
2.24 FEATURE — MOVE SEMANTICS
====================================================================

Move semantics allow resources to be transferred instead of
unnecessarily copied in appropriate situations.

Important concepts:

    - lvalue
    - rvalue
    - rvalue reference
    - std::move
    - move constructor
    - move assignment


Example concept:

    Copy:
        Resource A
            |
            | duplicate
            v
        Resource B


    Move:
        Resource A
            |
            | transfer ownership/resource
            v
        Resource B


Move semantics are important for performance in modern C++.


====================================================================
2.25 FEATURE — STATIC TYPING
====================================================================

C++ is statically typed.

This means types are generally known and checked during
compilation.

Example:

    int age = 25;

    double salary = 50000.0;


The compiler knows:

    age    -> int
    salary -> double


This enables many errors to be detected before execution.


====================================================================
2.26 FEATURE — STRONG TYPE SYSTEM
====================================================================

C++ has a strong and expressive type system, although it also
provides explicit conversions and low-level facilities.

Example:

    int x = 10;

    // explicit conversion
    double y = static_cast<double>(x);


C++ gives programmers control over when and how conversions occur.

|                      | control                 |
+----------------------+-------------------------+


IMPORTANT:

    C++ evolved from C, but modern C++ should not be treated as
    simply "C with classes."

2.39 WHAT IS MODERN C++?
====================================================================

Modern C++ generally refers to contemporary C++ practices,
especially those introduced from C++11 onward.

Instead of relying heavily on old-style C techniques:

    raw new/delete
    manual resource management
    C-style arrays everywhere
    C-style casts
    macros for ordinary logic

modern C++ commonly favors:

    RAII
    smart pointers
    STL containers
    algorithms
    range-based loops
    lambdas
    constexpr
    type-safe casts
    move semantics
    concepts where appropriate


OLD-STYLE:

    int* p = new int(10);

    // use p

    delete p;


MODERN STYLE:

    auto p = std::make_unique<int>(10);


The modern version automatically releases the resource
when the owning object goes out of scope.

2.41 BASIC STRUCTURE OF A C++ PROGRAM
====================================================================

Example:

    #include <iostream>

    int main()
    {
        std::cout << "Hello World";

        return 0;
    }


Let's understand each part.


--------------------------------------------------------------------
#include <iostream>
--------------------------------------------------------------------

#include is a preprocessing directive.

<iostream> provides facilities for standard input/output streams.

It allows us to use:

    std::cout
    std::cin


--------------------------------------------------------------------
int main()
--------------------------------------------------------------------

main() is the function where program execution begins
in a hosted C++ program.

The return type is:

    int


--------------------------------------------------------------------
{
--------------------------------------------------------------------

Opening curly brace starts the function body.


--------------------------------------------------------------------
std::cout
--------------------------------------------------------------------

cout is the standard output stream.

std::

means cout belongs to the std namespace.


--------------------------------------------------------------------
"Hello World"
--------------------------------------------------------------------

This is a string literal.


--------------------------------------------------------------------
;
--------------------------------------------------------------------

The semicolon terminates a statement.


--------------------------------------------------------------------
return 0;
--------------------------------------------------------------------

main() returns an integer value.

Returning 0 conventionally indicates successful termination
to the host environment.


--------------------------------------------------------------------
}
--------------------------------------------------------------------

Closes the function body.


====================================================================
2.42 WHAT IS main()?
====================================================================

The main function is the entry point of a hosted C++ program.

Example:

    int main()
    {
        // program starts here
    }


Another valid form is:

    int main(int argc, char* argv[])
    {
        // command-line arguments
    }


The second form allows the program to receive command-line arguments.


IMPORTANT:

    Standard C++ defines forms of main with implementation-defined
    details around the program startup environment, but the common
    hosted forms above are the ones you should know.


====================================================================
2.43 WHAT IS #include?
====================================================================

#include is a preprocessing directive.

Example:

    #include <iostream>


It makes declarations from the specified header available to
the translation unit according to the preprocessing rules.


Common headers:

    <iostream>
    <string>
    <vector>
    <algorithm>
    <map>
    <unordered_map>
    <memory>
    <fstream>


Examples:

    #include <iostream>
    #include <vector>
    #include <string>


====================================================================
2.44 WHAT IS std?
====================================================================

std is the namespace containing entities provided by the
C++ standard library.

Examples:

    std::cout
    std::cin
    std::string
    std::vector
    std::map
    std::sort


Example:

    std::string name = "Apoorv";


You may also write:

    using std::cout;

but beginners should generally understand the explicit:

    std::cout

style first.


====================================================================
2.45 WHAT IS A NAMESPACE?
====================================================================

A namespace is a mechanism for organizing names and reducing
name collisions.

Example:

    namespace College
    {
        int students = 100;
    }


Access:

    College::students


The C++ standard library uses:

    std


Therefore:

    std::vector
    std::string
    std::cout


The :: operator is called the scope resolution operator.


====================================================================
2.46 WHAT IS A STATEMENT?
====================================================================

A statement is an instruction that performs an action.

Example:

    int x = 10;

    x = x + 5;

    std::cout << x;


Many C++ statements end with:

    ;


But not every C++ construct is a simple semicolon-terminated
statement.


====================================================================
2.47 WHAT IS A BLOCK?
====================================================================

A block is a sequence of statements enclosed by:

    {
        ...
    }


Example:

    int main()
    {
        int x = 10;
        int y = 20;

        std::cout << x + y;
    }


The braces define the function body.


====================================================================
2.48 COMMENTS IN C++
====================================================================

Single-line comment:

    // This is a comment


Multi-line comment:

    /*
       This is a
       multi-line comment
    */


Comments are ignored for program execution.

Use comments to explain:

    - Why something is done
    - Complex logic
    - Important assumptions
    - Non-obvious decisions


Do not write unnecessary comments such as:

    int x = 10;  // assign 10 to x

if the code is already obvious.

2.50 HOW TO COMPILE A C++ PROGRAM
====================================================================

Suppose your file is:

    main.cpp


Using GCC:

    g++ main.cpp -o main


Then execute:

Linux/macOS:

    ./main


Windows:

    main.exe


Conceptual process:

    main.cpp
       |
       v
      g++
       |
       v
     main
       |
       v
    Execution


To select a standard explicitly:

    g++ -std=c++17 main.cpp -o main

or:

    g++ -std=c++20 main.cpp -o main

or:

    g++ -std=c++23 main.cpp -o main


The exact supported standard depends on your compiler/version.

C++ development.

2.55 TRANSLATION UNIT
====================================================================

A translation unit is, roughly, a source file after preprocessing,
along with the contents brought in by preprocessing directives
such as #include.

For example:

    main.cpp

may include:

    #include <iostream>


After preprocessing, the compiler sees a much larger translation
unit containing the relevant declarations/definitions from the
included headers.


This is an important concept for understanding:

    - Compilation
    - Header files
    - Include guards
    - One Definition Rule
    - Linker errors

2.57 COMMON C++ ERRORS
====================================================================

1. COMPILATION ERROR
--------------------

Example:

    int main()
    {
        int x = ;
    }


Compiler detects invalid syntax.


2. LINKER ERROR
---------------

Example concept:

    You declare a function but never provide a required definition.

The source may compile, but the linker may report an
"undefined reference" or similar unresolved symbol error.


3. RUNTIME ERROR
----------------

Example:

    Invalid memory access.


4. LOGICAL ERROR
----------------

Program runs but gives the wrong answer.


5. UNDEFINED BEHAVIOR
---------------------

Program violates rules for which the C++ standard does not
define the result.

Example:

    int arr[3] = {1, 2, 3};

    std::cout << arr[10];


This is an out-of-bounds access and has undefined behavior.

2.58 C++ PORTABILITY
====================================================================

Portability means the ability to use software across different
platforms with little or appropriate modification.

C++ is widely supported on:

    Windows
    Linux
    macOS
    Embedded platforms
    Other systems


However, C++ is not automatically perfectly portable.

Problems can arise from:

    - Platform-specific APIs
    - Compiler differences
    - Operating-system dependencies
    - Architecture differences
    - Non-standard extensions
    - Undefined behavior
    - Implementation-defined behavior


Good C++ programming aims to use standard language/library
features where portability is important.


====================================================================
2.59 C++ PERFORMANCE
====================================================================

C++ is known for high performance because it can provide:

    - Native machine-code compilation
    - Low runtime overhead when designed appropriately
    - Fine-grained memory/resource control
    - Efficient abstractions
    - Compile-time computation
    - Powerful optimization opportunities


But remember:

    C++ does NOT automatically make every program fast.

Performance depends on:

    - Algorithm
    - Data structures
    - Memory access patterns
    - Compiler optimization
    - I/O
    - Concurrency
    - Architecture
    - Program design


Example:

    O(n log n)

algorithm

can be much better than:

    O(n²)

for sufficiently large inputs, regardless of language.


Therefore:

    C++ + DSA + Good Design = Strong Performance Foundation

2.60 C++ ABSTRACTION
====================================================================

C++ allows programmers to build abstractions without necessarily
giving up efficient implementations.

Example:

    std::vector<int> numbers;

You can use:

    numbers.push_back(10);


without manually implementing every internal detail of a
dynamic array.


At the same time, C++ gives you access to lower-level concepts
when needed.


This balance is one of C++'s major strengths.

2.64 COMMON INTERVIEW QUESTIONS
====================================================================

Q1. What is C++?

ANSWER:
C++ is a general-purpose, multi-paradigm programming language
that supports high-level abstractions and low-level control.


Q2. Who created C++?

ANSWER:
Bjarne Stroustrup created C++, beginning with work on "C with
Classes" at Bell Labs.


Q3. Why was C++ created?

ANSWER:
It was developed to provide stronger abstraction and
object-oriented capabilities while retaining the efficiency
and systems-programming strengths associated with C.


Q4. Is C++ purely object-oriented?

ANSWER:
No. C++ is a multi-paradigm language supporting procedural,
object-oriented, generic and other programming styles.


Q5. What are the major features of C++?

ANSWER:

    - OOP
    - Templates
    - STL
    - Exception handling
    - Function overloading
    - Operator overloading
    - RAII
    - Smart pointers
    - Lambda expressions
    - Move semantics
    - Low-level control


Q6. What is Modern C++?

ANSWER:
Modern C++ generally refers to contemporary C++ practices and
features introduced especially from C++11 onward.


Q7. What is STL?

ANSWER:
STL is commonly used to refer to the Standard Template Library
components such as containers, iterators and algorithms.


Q8. What is RAII?

ANSWER:
RAII is a C++ resource-management technique in which resource
ownership/lifetime is tied to object lifetime, enabling automatic
cleanup through deterministic destruction.


Q9. What is the difference between C and C++?

ANSWER:
C is primarily procedural, while C++ is multi-paradigm and adds
features such as classes, templates, overloading, exceptions and
the C++ Standard Library.


Q10. Why is C++ considered fast?

ANSWER:
C++ can compile to efficient native code and provides low-level
control and low-overhead abstractions, although actual performance
depends heavily on algorithms, implementation and system design.


Q11. What is a namespace?

ANSWER:
A namespace is a mechanism for organizing names and reducing
name collisions.


Q12. What is std?

ANSWER:
std is the namespace containing entities provided by the
C++ Standard Library.


Q13. What is main()?

ANSWER:
main() is the entry point of a hosted C++ program.


Q14. What is a header file?

ANSWER:
A header commonly contains declarations and other definitions
intended to be made available to source files through inclusion.


Q15. What is the difference between compile-time and runtime?

ANSWER:
Compile-time refers to processing/translation of the program;
runtime refers to the period when the program is executing.


====================================================================
2.65 INTERVIEW TRICK QUESTIONS
====================================================================

QUESTION 1:

    "Is C++ an object-oriented language?"

BEST ANSWER:

    C++ supports object-oriented programming, but it is more
    accurately described as a multi-paradigm language.


---------------------------------------------------------------

QUESTION 2:

    "Is C++ compiled or interpreted?"

BEST ANSWER:

    C++ is typically compiled ahead of execution into native
    object/executable code by a compiler toolchain. The exact
    build and runtime process depends on the platform/toolchain.


---------------------------------------------------------------

QUESTION 3:

    "Is C++ faster than Python?"

BEST ANSWER:

    C++ often provides higher raw execution performance for
    compute-intensive workloads, but performance depends on the
    implementation, algorithm, workload and runtime environment.


---------------------------------------------------------------

QUESTION 4:

    "Does C++ provide garbage collection?"

BEST ANSWER:

    Standard C++ does not use a tracing garbage collector as its
    primary memory-management model. It emphasizes deterministic
    resource management, especially through RAII, smart pointers
    and object lifetime.


---------------------------------------------------------------

QUESTION 5:

    "Is C++ the same as C?"

BEST ANSWER:

    No. C++ evolved from C and shares significant syntax and
    concepts, but modern C++ is a distinct language with its own
    type system, object model, templates, standard library and
    language features.
