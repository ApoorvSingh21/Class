1.1 WHAT IS JAVASCRIPT?
====================================================================

JavaScript is a high-level, dynamically typed programming language
mainly used to make web pages interactive and to build applications.

Simple definition:

    JavaScript = A programming language used to add behavior and
                 logic to applications.

Example:

    HTML       → Structure
    CSS        → Appearance
    JavaScript → Behavior / Logic

Real-world analogy:

    Imagine a car:

        HTML       → Body of the car
        CSS        → Color, design, seats, appearance
        JavaScript → Engine and controls

Example:

    HTML can create a button:

        [ Click Me ]

    CSS can make the button beautiful.

    JavaScript can make the button perform an action when clicked.


====================================================================
1.2 WHY DO WE NEED JAVASCRIPT?
====================================================================

Without JavaScript, most web pages would primarily be static.

JavaScript allows us to:

    • Respond to button clicks
    • Validate forms
    • Change webpage content
    • Create animations
    • Make API requests
    • Communicate with servers
    • Store data in browsers
    • Create interactive applications
    • Build frontend applications
    • Build backend applications using Node.js
    • Create real-time applications
    • Build full-stack applications


Example:

    User clicks:

        [ Login ]

    JavaScript can:

        1. Read username
        2. Read password
        3. Validate input
        4. Send request to server
        5. Receive response
        6. Show success/error message

====================================================================
1.5 THREE WAYS TO ADD JAVASCRIPT TO HTML
====================================================================

JavaScript can be added to an HTML page in three common ways:

    1. Inline JavaScript
    2. Internal JavaScript
    3. External JavaScript


--------------------------------------------------------------------
1.5.1 INLINE JAVASCRIPT
--------------------------------------------------------------------

JavaScript is written directly inside an HTML element.

Example:

    <button onclick="alert('Hello')">
        Click Me
    </button>

Here:

    onclick
        ↓
    An event attribute.

When the button is clicked:

    alert("Hello")

executes.

Advantages:

    • Very simple
    • Useful for tiny demonstrations

Disadvantages:

    • Poor maintainability
    • Mixes HTML and JavaScript
    • Difficult to manage in large applications

Therefore:

    Avoid inline JavaScript in professional projects whenever
    possible.


--------------------------------------------------------------------
1.5.2 INTERNAL JAVASCRIPT
--------------------------------------------------------------------

JavaScript is written inside the HTML document using:

    <script>

Example:

    <!DOCTYPE html>
    <html>
    <head>
        <title>JavaScript</title>
    </head>

    <body>

        <h1>Hello</h1>

        <script>
            console.log("Hello from JavaScript");
        </script>

    </body>
    </html>

The JavaScript is inside the same HTML file.


--------------------------------------------------------------------
1.5.3 EXTERNAL JAVASCRIPT
--------------------------------------------------------------------

JavaScript is stored in a separate .js file.

HTML:

    <!DOCTYPE html>
    <html>
    <head>
        <title>JavaScript</title>
    </head>

    <body>

        <h1>Hello JavaScript</h1>

        <script src="app.js"></script>

    </body>
    </html>


app.js:

    console.log("Hello from external JavaScript");


This is the recommended approach for most real-world projects.

Advantages:

    ✓ Cleaner HTML
    ✓ Better organization
    ✓ Easier maintenance
    ✓ Reusable JavaScript
    ✓ Better separation of concerns
    ✓ Suitable for large applications


====================================================================
1.6 SCRIPT TAG
====================================================================

The HTML:

    <script>

element is used to include JavaScript.

Example:

    <script>
        console.log("Hello");
    </script>

External JavaScript:

    <script src="app.js"></script>


The src attribute means:

    src = source

It tells the browser where the JavaScript file is located.


Example:

    <script src="./js/app.js"></script>


Meaning:

    HTML file
        ↓
    js folder
        ↓
    app.js


====================================================================
1.7 defer ATTRIBUTE
====================================================================

A script can use:

    defer

Example:

    <script src="app.js" defer></script>

It tells the browser to download the script while parsing the HTML
and execute it after the HTML has been parsed.

For many frontend applications, this is a useful way to load
scripts placed in the <head>.

Example:

    <head>
        <script src="app.js" defer></script>
    </head>


====================================================================
1.8 async ATTRIBUTE
====================================================================

Another script-loading option is:

    async

Example:

    <script src="analytics.js" async></script>

The browser downloads the script asynchronously and executes it as
soon as it is ready.

Important difference:

    defer
        → Download in parallel
        → Execute after HTML parsing
        → Preserves script order

    async
        → Download in parallel
        → Execute as soon as ready
        → Order is not guaranteed

For dependent scripts, defer is often more appropriate.


====================================================================
1.9 JAVASCRIPT STATEMENTS
====================================================================

A statement is an instruction that tells JavaScript to perform
an operation.

Example:

    let age = 22;

This is a statement.

Another example:

    console.log(age);

This is also a statement.


Multiple statements:

    let name = "Apoorv";
    let age = 22;
    console.log(name);
    console.log(age);


JavaScript executes statements according to its execution rules.


====================================================================
1.10 SEMICOLON
====================================================================

JavaScript commonly uses:

    ;

to terminate statements.

Example:

    let x = 10;
    let y = 20;
    console.log(x + y);


JavaScript has Automatic Semicolon Insertion (ASI), so semicolons
can sometimes be omitted.

Example:

    let x = 10
    let y = 20

However, for beginners and professional consistency, it is useful
to understand and follow one consistent code style.


====================================================================
1.11 EXPRESSION
====================================================================

An expression is code that produces a value.

Example:

    10 + 20

Result:

    30


Another example:

    5 * 4

Result:

    20


Another:

    age > 18

Result:

    true or false


Example:

    let result = 10 + 20;

Here:

    10 + 20
       ↓
    Expression

    let result = 10 + 20;
       ↓
    Complete statement


Important:

    Expression → produces a value
    Statement  → performs an instruction/action

A statement can contain expressions.


====================================================================
1.12 COMMENTS
====================================================================

Comments are notes written in code for humans.

JavaScript ignores comments during normal execution.


--------------------------------------------------------------------
SINGLE-LINE COMMENT
--------------------------------------------------------------------

Use:

    //

Example:

    // This is a comment
    console.log("Hello");


--------------------------------------------------------------------
MULTI-LINE COMMENT
--------------------------------------------------------------------

Use:

    /*
       This is a
       multi-line comment
    */

Example:

    /*
       This program
       prints a message.
    */

    console.log("Hello");


Why use comments?

    • Explain complicated logic
    • Document code
    • Help teammates understand code
    • Temporarily disable code while debugging

Avoid unnecessary comments such as:

    // Create variable x
    let x = 10;

The code is already obvious.

Prefer comments that explain WHY something is done when the reason
isn't obvious from the code.

====================================================================

A variable is a named location/reference used by a program to
work with a value.

Simple analogy:

    Variable = A labeled box containing a value.

Example:

    let age = 22;


Think:

        age
         ↓
       [ 22 ]

Another example:

    let name = "Apoorv";

        name
         ↓
      ["Apoorv"]


Variables allow programs to store and work with data.


====================================================================
1.14 VARIABLE DECLARATION
====================================================================

Declaration means telling JavaScript that a variable exists.

Example:

    let age;

Here:

    age

has been declared.

At this point, it has not been explicitly assigned a value.


====================================================================
1.15 VARIABLE INITIALIZATION
====================================================================

Initialization means giving a variable its initial value.

Example:

    let age = 22;

Here:

    let age
        ↓
    declaration

    = 22
        ↓
    initialization


====================================================================
1.16 ASSIGNMENT
====================================================================

Assignment means giving or changing the value of a variable.

Example:

    let age = 22;

Later:

    age = 23;

The value changes:

    Before:

        age → 22

    After:

        age → 23


Important:

    =

is the assignment operator.

It does NOT mean mathematical equality.

Example:

    let x = 10;

means:

    Store 10 in x.


====================================================================
1.17 var
====================================================================

Before modern JavaScript, variables were commonly declared using:

    var

Example:

    var age = 22;

The value can be changed:

    var age = 22;
    age = 23;


var is function-scoped rather than block-scoped and has historical
behavior around hoisting and redeclaration.

Example:

    var x = 10;

    if (true) {
        var x = 20;
    }

    console.log(x);

Output:

    20

This behavior can cause bugs in larger programs.


====================================================================
1.18 let
====================================================================

Modern JavaScript provides:

    let

Example:

    let age = 22;

The value can be changed:

    let age = 22;

    age = 23;

    console.log(age);

Output:

    23


let is block-scoped.

Example:

    let x = 10;

    if (true) {
        let x = 20;
        console.log(x);
    }

    console.log(x);

Output:

    20
    10

There are two different block-scoped variables.


====================================================================
1.19 const
====================================================================

const is used when a variable binding should not be reassigned.

Example:

    const PI = 3.14159;

This is not allowed:

    const PI = 3.14159;

    PI = 3.14;

This causes an error because the binding cannot be reassigned.


Example:

    const name = "Apoorv";

    name = "Rahul";

Not allowed.


====================================================================
1.20 var vs let vs const
====================================================================

                    var         let          const
                    ------------------------------------
Scope               Function     Block        Block

Reassign            Yes          Yes          No

Redeclare same
scope               Yes          No           No

Hoisting behavior   Yes          Yes*         Yes*

Initialization
required            No           No           Yes

Recommended today   Rarely       Yes          Yes


* let and const are hoisted but cannot be accessed before their
  declaration because of the Temporal Dead Zone.


Recommended rule:

    Use const by default.

    Use let when reassignment is required.

    Avoid var in modern code unless you specifically need its
    historical/function-scoped behavior.


====================================================================
1.21 const DOES NOT MEAN IMMUTABLE OBJECT
====================================================================

This is a very important concept.

Example:

    const user = {
        name: "Apoorv"
    };

You cannot do:

    user = {};

because the variable binding cannot be reassigned.

But you can modify the object's property:

    user.name = "Rahul";

This is allowed.

Therefore:

    const
        ↓
    prevents reassignment of the binding

It does NOT automatically make the referenced object immutable.


Similarly:

    const numbers = [1, 2, 3];

    numbers.push(4);

is allowed.

But:

    numbers = [5, 6, 7];

is not allowed.

1.22 IDENTIFIERS
====================================================================

An identifier is a name used for program entities such as:

    • Variables
    • Functions
    • Classes
    • Parameters

Example:

    let studentName = "Apoorv";

Here:

    studentName

is an identifier.


====================================================================
1.23 IDENTIFIER RULES
====================================================================

JavaScript identifiers generally:

    ✓ Can contain letters
    ✓ Can contain digits
    ✓ Can contain _
    ✓ Can contain $
    ✓ Cannot begin with a digit
    ✓ Are case-sensitive
    ✓ Cannot be reserved keywords


Valid:

    name
    studentName
    student_name
    student1
    $price
    _count


Invalid:

    1student
    student-name
    let
    class


Why is:

    student-name

problematic?

Because JavaScript interprets:

    student - name

as subtraction rather than a single identifier.


====================================================================
1.24 CASE SENSITIVITY
====================================================================

JavaScript is case-sensitive.

These are different:

    name
    Name
    NAME
    nAME


Example:

    let name = "Apoorv";
    let Name = "Rahul";

These are two different variables.


====================================================================
1.25 NAMING CONVENTIONS
====================================================================

JavaScript commonly uses camelCase.

Example:

    firstName
    lastName
    studentAge
    totalMarks
    employeeSalary


Avoid unclear names:

    let x = 25;

Prefer:

    let studentAge = 25;


Bad:

    let a = 100;
    let b = 200;
    let c = a + b;


Better:

    let firstNumber = 100;
    let secondNumber = 200;
    let total = firstNumber + secondNumber;


Good naming improves readability and maintainability.


====================================================================
1.26 CONSTANT NAMING CONVENTION
====================================================================

Constants that represent fixed configuration-like values are often
written in UPPER_SNAKE_CASE.

Example:

    const MAX_USERS = 100;
    const API_URL = "https://example.com";


But not every const variable needs uppercase naming.

Example:

    const userName = "Apoorv";

This is perfectly normal.

Convention depends on the meaning and project style.

1.28 JAVASCRIPT CONSTANTS
====================================================================

A constant is generally represented using:

    const

Example:

    const DAYS_IN_WEEK = 7;
    const MONTHS_IN_YEAR = 12;

Useful when the console has accumulated too many messages.

1.38 COMMON BEGINNER MISTAKES
====================================================================

MISTAKE 1:

    let 1name = "Apoorv";

Wrong.

Correct:

    let name1 = "Apoorv";


MISTAKE 2:

    const age;
    age = 22;

A const declaration must be initialized.

Correct:

    const age = 22;


MISTAKE 3:

    const age = 22;
    age = 23;

Wrong because const cannot be reassigned.


MISTAKE 4:

    let student-name = "Apoorv";

Wrong.

Use:

    let studentName = "Apoorv";


MISTAKE 5:

    let Name = "Apoorv";

    console.log(name);

Wrong because JavaScript is case-sensitive.


MISTAKE 6:

    var x = 10;

    if (true) {
        var x = 20;
    }

    console.log(x);

Beginners may expect 10, but var is function-scoped and the same
binding is affected here.

1.39 PROFESSIONAL JAVASCRIPT STYLE
====================================================================

Prefer:

    const userName = "Apoorv";
    let score = 0;

    score = score + 10;

Instead of unnecessarily using:

    var userName = "Apoorv";


Use meaningful names:

    const studentName = "Apoorv";
    const totalMarks = 450;


Instead of:

    const s = "Apoorv";
    const t = 450;


Professional code should be:

    • Readable
    • Consistent
    • Maintainable
    • Meaningful
    • Simple

1.41 JAVASCRIPT EXECUTION — BASIC VIEW
====================================================================

When JavaScript code runs, conceptually:

    JavaScript Source Code
             ↓
        JavaScript Engine
             ↓
          Parsing
             ↓
        Execution
             ↓
           Output


Example:

    const x = 10;
    const y = 20;
    console.log(x + y);


Conceptually:

    x → 10
    y → 20

    x + y
      ↓
     30

    console.log(30)
      ↓
    Console output


You will study the JavaScript engine, execution context,
call stack, and event loop deeply in later chapters.

1.43 IMPORTANT DIFFERENCE:
     console.log() vs alert()
====================================================================

console.log():

    console.log("Hello");

Displays information in the developer console.

alert():

    alert("Hello");

Displays a browser alert dialog.

For development/debugging:

    console.log()

is generally much more useful than repeatedly using alert().

1.45 INTERVIEW-IMPORTANT QUESTIONS

Q1. What is JavaScript?

Answer:

    JavaScript is a high-level programming language widely used

    application environments.


Q2. What are the ways to include JavaScript in HTML?

Answer:

    2. Internal
    3. External


Q3. What is the difference between let and const?

Answer:

    let allows reassignment.

Q4. What is the difference between var and let?

Answer:

    let is block-scoped.

Answer:

    Yes.

Answer:

    A statement is an instruction executed by the JavaScript
    program.


Q8. What is an expression?

Answer:

    An expression is code that evaluates to a value.


Q9. What is console.log()?

Answer:

    console.log() is a console method used to display information,
    values, and debugging output.


Q10. Can a const object be modified?

Answer:

    Its binding cannot be reassigned, but its properties can
    generally be modified unless the object is made immutable.

1.48 MINI PROJECT — STUDENT MARKS CALCULATOR
====================================================================

Create a JavaScript program containing:

    studentName
    subject1
    subject2
    subject3

Calculate:

    totalMarks
    averageMarks

Print:

    =========================
       STUDENT RESULT
    =========================

    Name:
    Subject 1:
    Subject 2:
    Subject 3:
    Total:
    Average:


Example:

    const studentName = "Apoorv";

    const subject1 = 80;

    const totalMarks = subject1 + subject2 + subject3;
    const averageMarks = totalMarks / 3;

    console.log("===== STUDENT RESULT =====");

1.50 MOST IMPORTANT TAKEAWAYS
====================================================================

1. JavaScript is a programming language used to add logic and
   interactivity to applications.

2. JavaScript can run in browsers and environments such as Node.js.

3. JavaScript can be added to HTML using:
       Inline
       Internal
       External

4. Prefer external JavaScript for organized applications.

5. A variable allows a program to work with stored values.

6. Modern JavaScript generally prefers:
       const
       let

7. Use const by default when reassignment is not required.

8. Use let when reassignment is required.

9. var is function-scoped and has historical behavior that can
   make large codebases harder to reason about.

10. JavaScript identifiers are case-sensitive.

11. Statements represent instructions.

12. Expressions produce values.

13. Comments are ignored by JavaScript during normal execution.

14. console.log() is one of the most important tools for learning
    and debugging JavaScript.

15. Do not memorize syntax only.
    Write programs and predict outputs yourself.
